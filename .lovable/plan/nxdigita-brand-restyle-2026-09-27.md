# NxDigita brand restyle

## Goal
Apply the supplied NxDigita brand system across the existing home and sign-up pages while preserving all current content, sections, and the **Hire · Engage · Deploy** model.

## Visual changes
- Replace the current electric-blue theme with deep navy, charcoal, orange, and cyan using the supplied brand values.
- Use the dark-panel gradient for major dark sections and introduce clean light surfaces where they improve hierarchy.
- Change headings to **Manrope** and body text to **DM Sans**.
- Restyle buttons, labels, links, icons, cards, borders, metrics, the certificate, and the sign-up form consistently.
- Rework the opening section’s visual language toward the supplied NxDigita reference: bold orange emphasis, restrained cyan technical accents, subtle orbital/grid motifs, and a clearer primary action.
- Keep the uploaded screenshot as design reference only; it will not be embedded.

## Verification
- Check the home and sign-up pages at desktop and mobile widths.
- Confirm navigation, anchor links, sharing links, form states, and motion still work.
- Confirm the app builds and renders without console or runtime errors.

## Technical details
- Define every new visual value as a semantic token in the shared stylesheet.
- Load Manrope and DM Sans through the document head.
- Keep the existing section-component structure and routing unchanged.
